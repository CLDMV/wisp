# `@cldmv/wisp` v1.0.8 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `release/1.0.8`

---

## Overview

A one-line development-dependency patch: `@types/node` 26.6.3 → 26.6.4 ([#46](https://github.com/CLDMV/wisp/pull/46)). The only files that differ from [v1.0.7](./v1.0.7.md) are `package.json` (the version number) and `package-lock.json`. The `package.json` range `^26.6.2` already allowed the new version, so the lockfile is the only place the bump is recorded.

`@types/node` is a development dependency used by the TypeScript type check (`npm run types:check`, part of `npm run build:ci`). It does not enter the published tarball, which still contains only `dist/`, `types/`, `README.md` and `LICENSE`, and the package still has no runtime dependencies. With the bump in place `npm run build:ci` (lint, format check, `tsc`, the build, the test suite and the type check) passes.
